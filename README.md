# 荐力 Letterwise

作者：Leon Fang

填写三位推荐人，评估 PhD 推荐信组合强度，自动生成分数解读和调整建议。

## 使用

直接在浏览器打开 `index.html` 即可使用，页面不依赖外部字体、脚本或服务。

也可以使用 Node.js 20 或更新版本运行：

```sh
npm run dev
```

打开终端显示的本地地址。无需安装依赖。

## 功能

白底黑字界面，保留表单、进度与结果。

- 三位推荐人以编号区分，只需选择学校档次和相关背景。
- 填写页只显示进度，完成后统一查看个人分、组合分和解读。
- 结果页逐项展示基础分、地区修正、学校加分与百分制换算。
- 自动生成评级、组合短板分析、每位推荐人的逐项解释和调整建议。
- 结果页解释各项权重、百分制换算与最低分修正的原因。
- 浏览器本地保存、虚构示例、清空重填。
- 导出 Markdown 解读报告，或打印保存 PDF。
- 手机、平板和电脑布局。

## 评分规则 v1.0

| 基础项目 | 分值 |
| --- | --- |
| 指导关系 | 研究推 20，课程推 10，职业推 0 |
| 推荐力度 | 明确积极推荐 10，合作超过 6 个月 5，线下合作 5 |
| 方向匹配 | 同 field 25，同 school 20，跨 school 有联系 15，无联系 0 |
| 近两年学术活跃度 | 持续且有较强代表作 15，持续 10，少量 5，无 0 |
| 职称资历 | 正教授 20，副教授 15，助理教授 10，其他 0 |

纯课程推的方向匹配为 0。school 指学科所属学院。恰好 6 个月不计“超过 6 个月”的加分。

地区只取一档：目前在申请地任职 +20，曾在申请地正式任职 +15，曾在申请地取得 PhD +10，曾在申请地访问或做博后 +5，无相关匹配但有其他海外背景 0，无相关匹配且纯国内背景 −5。

学校按当前任职学校判断，只取一档：清北 / 美国专业排名前 20 / 英国 G5 加 10；其他 Top 985 / 美国专业排名 21–50 / 英国前 10 非 G5 加 5；其他加 0。档位由使用者选择，尚未接入实时排名数据库。Top 985 按目标学科认定。

```text
原始分 = 五项基础分 + 地区修正 + 学校加分（最高 130）
单人分 = round(max(0, 原始分) ÷ 130 × 100)
组合分 = round(三位单人未取整分的均值 × 80% + 最低值 × 20%)
```

单人显示分取整。组合分使用取整前的数值计算，最后取整一次。未填齐的评分项保持待评估。

| 分数 | 解读 |
| --- | --- |
| 0–49 | 不及格，建议换推荐人 |
| 50–59 | 偏弱，建议优化推荐人组合 |
| 60–79 | 还行 |
| 80–89 | 很强 |
| 90–100 | 无敌 |

分数衡量自定义规则下的推荐人组合强度，不表示录取概率。

## 发布到 GitHub Pages

将项目文件放入 GitHub 仓库的 `main` 分支，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**，再手动运行 **Publish Letterwise** 工作流。

每次提交会自动运行测试与构建。手动运行发布工作流时，会依次测试、准备 `dist/` 并发布页面。使用相对资源路径，支持仓库子路径部署。工作流配置依据 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

也可以直接把 `dist/` 部署到任意静态网站服务。

## 开发

```sh
npm test
npm run build
```

`scoring.js` 管理规则、计算和解读；`app.js` 管理界面与本地保存；`style.css` 管理布局与外观。测试覆盖分值、评级边界、地区互斥、课程推、缺失数据和组合计算。

## 数据

推荐人信息保存在当前浏览器的 localStorage，页面没有提交这些内容的网络接口。导出报告在浏览器本地生成。
